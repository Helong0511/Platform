# 数据库表管理工具 - 使用说明

## 📋 工具概述

这是一个基于Python Tkinter开发的数据库表管理工具，专门用于管理Platform平台的数据库表结构。工具能够自动识别和分类CPL系统相关表，提供友好的图形界面进行表结构查看和数据管理。

## ✨ 主要功能

### 1. SQL文件解析
- 自动解析SQL文件，提取所有表的定义
- 识别表结构、字段、索引、外键等信息
- 提取表注释和字段注释

### 2. CPL表分类管理
- **CPL表系列**：自动识别13个CPL系统核心表
- **其他表**：显示其他业务表（产品、客户、用户等）
- 分类显示，便于快速定位

### 3. 表结构查看
- 字段详细信息（名称、类型、是否可空、默认值、注释）
- 索引列表（普通索引、唯一索引）
- 外键关系（关联表和字段）
- 表注释说明

### 4. 数据浏览（需连接数据库）
- 查看表数据
- 支持分页显示
- 可自定义每页显示数量
- 实时刷新数据

### 5. SQL查询执行（需连接数据库）
- 执行自定义SQL查询
- 支持SELECT、INSERT、UPDATE、DELETE等操作
- 显示查询结果或执行状态
- 自动事务提交

## 📦 安装步骤

### 1. 安装Python依赖

```bash
pip install mysql-connector-python
```

或者使用requirements文件：

```bash
pip install -r requirements_db_manager.txt
```

### 2. 确认SQL文件位置

确保SQL文件位于：`scripts/data/platform20251230.sql`

如果文件在其他位置，工具启动时会提示选择文件。

### Windows系统

**方法1：直接运行Python脚本**
```bash
cd scripts
python db_manager_gui.py
```


## 📖 操作指南

### 第一步：启动工具

运行工具后，界面会自动尝试加载默认SQL文件（`scripts/data/platform20251230.sql`）。

如果文件不存在，会弹出文件选择对话框。

### 第二步：查看表结构（无需连接数据库）

1. 在左侧面板选择表分类：
   - **CPL表系列**：查看CPL系统相关表
   - **其他表**：查看其他业务表

2. 点击表名，右侧会显示：
   - **表结构**标签页：显示表的详细结构信息
   - 包括字段列表、索引、外键等

### 第三步：连接数据库（可选，用于查看数据）

1. 点击顶部工具栏的"连接数据库"按钮
2. 填写连接信息：
   ```
   主机: localhost (或数据库服务器IP)
   端口: 3306
   用户名: root (或数据库用户名)
   密码: (数据库密码)
   数据库: platform (或目标数据库名)
   ```
3. 点击"连接"按钮

### 第四步：查看表数据

1. 选择要查看的表
2. 切换到"表数据"标签页
3. 可以：
   - 设置每页显示数量（10-1000条）
   - 点击"刷新数据"更新显示
   - 查看表中的所有数据

### 第五步：执行SQL查询

1. 切换到"SQL查询"标签页
2. 在文本框中输入SQL语句，例如：
   ```sql
   SELECT * FROM clicks LIMIT 10;
   SELECT COUNT(*) FROM offers WHERE is_active = 1;
   UPDATE offers SET status = 'Active' WHERE id = 1;
   ```
3. 点击"执行查询"按钮
4. 查看执行结果或错误信息

## 🎨 界面说明

### 顶部工具栏
- **加载SQL文件**：重新加载SQL文件
- **连接数据库**：连接/断开数据库
- **刷新**：刷新表列表和数据

### 左侧面板
- **CPL表系列**标签页：显示所有CPL系统相关表
- **其他表**标签页：显示其他业务表
- 每个表显示表名和注释

### 右侧面板
- **表结构**标签页：
  - 表基本信息（名称、类型、注释）
  - 字段列表（名称、类型、约束、注释）
  - 索引列表
  - 外键列表

- **表数据**标签页：
  - 数据表格显示
  - 分页控制
  - 刷新按钮

- **SQL查询**标签页：
  - SQL输入框
  - 执行按钮
  - 结果显示区域

### 底部状态栏
显示当前操作状态和提示信息

## ⚠️ 注意事项

1. **首次使用**：需要先加载SQL文件来解析表结构
2. **数据库连接**：查看数据和执行查询需要先连接数据库
3. **SQL执行**：执行非SELECT语句（INSERT/UPDATE/DELETE）会自动提交事务，请谨慎操作
4. **数据量限制**：表数据默认每页显示100条，SQL查询结果最多显示100行
5. **权限要求**：确保数据库用户有足够的权限执行查询和操作

## 🔧 故障排除

### 问题1：无法加载SQL文件
**解决方案**：
- 检查文件路径是否正确
- 确认文件编码为UTF-8
- 确保SQL文件包含CREATE TABLE语句

### 问题2：数据库连接失败
**解决方案**：
- 检查数据库服务是否运行
- 验证连接参数（主机、端口、用户名、密码）
- 检查防火墙设置
- 确认用户权限

### 问题3：表结构解析不完整
**解决方案**：
- 检查SQL文件格式是否正确
- 确保CREATE TABLE语句完整
- 查看错误提示信息

### 问题4：执行SQL查询报错
**解决方案**：
- 检查SQL语法是否正确
- 确认表名和字段名正确
- 检查用户权限是否足够
- 查看错误信息详情
