# 前端下拉选择框修复计划

## 问题总结

经过详细检查，发现前端下拉选择框存在以下主要问题：

### 1. 高优先级问题

* **Popper配置和Z-Index层级冲突** - 下拉选项被对话框遮挡

* **Placeholder遮盖选中值** - 选中值被placeholder遮挡

* **下拉选项被对话框遮挡** - 即使使用`:append-to-body`仍有问题

### 2. 中优先级问题

* **Overflow裁剪** - 父容器裁剪下拉选项

* **移动端响应式问题** - 宽度和触摸目标尺寸不足

## 修复方案

### 方案1：统一添加Popper配置（推荐）

为所有`el-select`组件添加以下属性：

```vue
<el-select
  v-model="xxx"
  popper-class="select-dropdown"
  :teleported="true"
  :popper-options="{
    strategy: 'fixed',
    modifiers: [
      {
        name: 'offset',
        options: {
          offset: [0, 8]
        }
      }
    ]
  }"
>
```

### 方案2：优化CSS样式

* 移除OfferManagement.vue中大量的CSS补丁代码（第1574-1748行）

* 添加全局CSS类`.select-dropdown`统一管理下拉选项样式

### 方案3：修复移动端样式

* 统一移动端下拉框宽度为100%

* 确保触摸目标尺寸至少44px
