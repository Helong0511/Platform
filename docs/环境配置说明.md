# 环境配置说明

## 环境概览

本项目支持两个环境：

### 1. 生产环境（Production）
- **操作系统**: Ubuntu 22.04.5 LTS
- **项目目录**: `/data/Platform`
- **用途**: 正式生产服务器
- **特点**: 
  - 使用 Systemd 服务管理
  - 使用 Nginx 作为反向代理
  - 严格的权限控制
  - 完整的日志记录

### 2. 测试环境（Development/Testing）
- **操作系统**: Windows 10/11
- **项目目录**: `E:\data\Platform`
- **用途**: 本地开发和测试
- **特点**:
  - 直接运行 Python 脚本
  - 开发调试模式
  - 相对宽松的权限要求

## 环境检测

### 自动检测机制

项目脚本会自动检测当前环境：

1. **操作系统检测**: 通过 `platform.system()` 检测 Windows 或 Linux
2. **项目路径检测**: 检测项目根目录路径
3. **环境变量检测**: 通过 `PRODUCTION_ENV` 环境变量判断

### 检测逻辑

```python
# 生产环境判断
is_ubuntu_prod = project_path == "/data/Platform"

# 测试环境判断
is_windows_test = IS_WINDOWS and "E:\\data\\Platform" in project_path

# 环境类型
is_production = PRODUCTION_ENV in ["production", "prod"]
```

## 配置文件

### .env 文件配置

#### 生产环境（Ubuntu）
```bash
# 环境类型
PRODUCTION_ENV=production

# 项目路径相关配置
# RSA 密钥路径（使用绝对路径）
RSA_PRIVATE_KEY_PATH=/data/Platform/keys/private_key.pem
RSA_PUBLIC_KEY_PATH=/data/Platform/keys/public_key.pem

# 日志路径
LOG_DIR=/data/Platform/logs
```

#### 测试环境（Windows）
```bash
# 环境类型
PRODUCTION_ENV=development

# 项目路径相关配置
# RSA 密钥路径（可以使用相对路径或绝对路径）
RSA_PRIVATE_KEY_PATH=keys/private_key.pem
# 或
RSA_PRIVATE_KEY_PATH=E:\data\Platform\keys\private_key.pem
RSA_PUBLIC_KEY_PATH=keys/public_key.pem
# 或
RSA_PUBLIC_KEY_PATH=E:\data\Platform\keys\public_key.pem

# 日志路径（相对路径）
LOG_DIR=logs
```

## 路径处理

### 跨平台路径兼容

所有脚本都使用 `pathlib.Path` 处理路径，自动兼容 Windows 和 Linux：

```python
from pathlib import Path

# 自动处理路径分隔符
project_root = Path(__file__).parent.parent
keys_dir = project_root / "keys"  # 跨平台兼容

# 转换为字符串时使用 as_posix() 确保跨平台兼容
path_str = keys_dir.absolute().as_posix()
```

### 路径配置建议

1. **生产环境（Ubuntu）**: 使用绝对路径
   ```bash
   RSA_PRIVATE_KEY_PATH=/data/Platform/keys/private_key.pem
   ```

2. **测试环境（Windows）**: 可以使用相对路径或绝对路径
   ```bash
   # 相对路径（推荐，便于迁移）
   RSA_PRIVATE_KEY_PATH=keys/private_key.pem
   
   # 绝对路径（也可以）
   RSA_PRIVATE_KEY_PATH=E:\data\Platform\keys\private_key.pem
   ```

## 工具脚本使用

### 配置检查工具

```bash
# 生产环境（Ubuntu）
cd /data/Platform
python3 scripts/check_config.py

# 测试环境（Windows）
cd E:\data\Platform
python scripts/check_config.py
```

工具会自动检测：
- 当前操作系统
- 项目路径
- 环境类型（生产/开发）
- 路径配置是否正确

### RSA 密钥生成工具

```bash
# 生产环境（Ubuntu）
cd /data/Platform
python3 scripts/generate_rsa_keys.py --output-dir /data/Platform/keys

# 测试环境（Windows）
cd E:\data\Platform
python scripts/generate_rsa_keys.py --output-dir keys
# 或
python scripts/generate_rsa_keys.py --output-dir E:\data\Platform\keys
```

## 环境差异对比

| 项目 | 生产环境（Ubuntu） | 测试环境（Windows） |
|------|-------------------|-------------------|
| **项目路径** | `/data/Platform` | `E:\data\Platform` |
| **路径分隔符** | `/` | `\` 或 `/` |
| **权限管理** | 使用 `chmod`/`chown` | 文件系统权限 |
| **服务管理** | Systemd | 直接运行 |
| **Web 服务器** | Nginx + Gunicorn | 开发服务器 |
| **日志位置** | `/data/Platform/logs` | `E:\data\Platform\logs` |
| **密钥位置** | `/data/Platform/keys` | `E:\data\Platform\keys` |
| **环境变量** | `.env` + Systemd | `.env` 文件 |
| **Python 路径** | `/data/Platform/venv/bin/python` | `E:\data\Platform\.venv\Scripts\python.exe` |

## 常见问题

### Q: 如何确认当前环境？

运行配置检查工具：
```bash
python scripts/check_config.py
```

工具会显示：
- 项目路径
- 操作系统
- 环境类型
- 路径配置状态

### Q: 如何在两个环境间迁移配置？

1. **导出配置**（从生产环境）:
   ```bash
   # 注意：不要导出敏感信息（如密钥文件）
   # 只导出 .env 文件（已排除敏感信息）
   ```

2. **导入配置**（到测试环境）:
   - 复制 `.env` 文件
   - 修改路径配置为相对路径或 Windows 路径
   - 修改 `PRODUCTION_ENV=development`
   - 重新生成密钥对（不要使用生产环境的密钥）

### Q: 路径配置错误怎么办？

1. 检查 `.env` 文件中的路径配置
2. 运行 `python scripts/check_config.py` 查看详细错误
3. 根据错误提示修复路径配置
4. 确保路径使用正确的分隔符和格式

### Q: 两个环境可以使用相同的密钥吗？

**不建议**。建议：
- 生产环境使用生产密钥
- 测试环境使用测试密钥
- 密钥文件不要提交到版本控制系统
