# 清理过期会话和黑名单任务说明

## 概述

清理过期会话和黑名单记录是一个定时任务，用于自动清理数据库中过期的会话记录和黑名单记录，保持数据库的整洁和性能。

## 功能说明

### 清理规则

1. **删除过期会话记录**：删除过期超过30天的会话记录
2. **删除过期黑名单记录**：删除过期超过30天的黑名单记录
3. **标记非活跃会话**：将超过7天未活动的会话标记为非活跃状态

### 执行时间

建议每天凌晨2点执行（Cron表达式：`0 2 * * *`）

## 安装和配置

### 1. 创建数据库任务

执行SQL脚本创建定时任务：

```bash
mysql -u root -p platform < scripts/create_cleanup_sessions_task.sql
```

或者在MySQL客户端中执行：

```sql
USE platform;

INSERT INTO `scheduled_tasks` (
    `task_name`,
    `function_path`,
    `cron_expression`,
    `description`,
    `is_active`,
    `created_at`,
    `updated_at`
) VALUES (
    '清理过期会话和黑名单',
    'app.scheduler_module.tasks.cleanup_expired_sessions.cleanup_expired_sessions',
    '0 2 * * *',
    '清理过期超过30天的会话记录和黑名单记录，标记超过7天未活动的会话为非活跃',
    TRUE,
    NOW(),
    NOW()
) ON DUPLICATE KEY UPDATE
    `function_path` = VALUES(`function_path`),
    `cron_expression` = VALUES(`cron_expression`),
    `description` = VALUES(`description`),
    `is_active` = VALUES(`is_active`),
    `updated_at` = NOW();
```

### 2. 重启应用

任务创建后，需要重启应用以加载新的定时任务：

```bash
# 如果使用systemd
sudo systemctl restart platform

# 如果使用Docker
docker-compose restart backend
```

### 3. 验证任务已注册

查看应用日志，确认任务已成功注册：

```
定时任务已注册: '清理过期会话和黑名单' (Cron: 0 2 * * *) - 清理过期超过30天的会话记录和黑名单记录...
```

## 手动执行

如果需要手动执行清理任务，可以通过以下方式：

### 方式1：使用SQL脚本

```bash
mysql -u root -p platform < scripts/cleanup_expired_sessions.sql
```

### 方式2：使用Python脚本

```python
import asyncio
from app.scheduler_module.tasks.cleanup_expired_sessions import cleanup_expired_sessions

async def main():
    result = await cleanup_expired_sessions()
    print(f"清理结果: {result}")

if __name__ == "__main__":
    asyncio.run(main())
```

如果实现了任务执行API，可以通过API手动触发任务执行。

## 监控和日志

### 查看执行日志

任务执行后，会在应用日志中记录清理结果：

```
清理了 10 条过期会话记录
清理了 5 条过期黑名单记录
标记了 3 个非活跃会话
清理完成：删除了 10 条会话记录，5 条黑名单记录，标记了 3 个非活跃会话
```

### 查看数据库状态

```sql
-- 查看会话表记录数
SELECT COUNT(*) as total_sessions,
       SUM(CASE WHEN is_active = TRUE THEN 1 ELSE 0 END) as active_sessions,
       SUM(CASE WHEN expires_at < NOW() THEN 1 ELSE 0 END) as expired_sessions
FROM user_sessions;

-- 查看黑名单表记录数
SELECT COUNT(*) as total_blacklist,
       SUM(CASE WHEN expires_at < NOW() THEN 1 ELSE 0 END) as expired_blacklist
FROM token_blacklist;
```

## 自定义清理规则

如果需要修改清理规则（例如修改过期天数），可以编辑 `app/scheduler_module/tasks/cleanup_expired_sessions.py`：

```python
# 修改过期时间阈值（例如改为60天）
expired_threshold = datetime.now(timezone.utc) - timedelta(days=60)

# 修改非活跃时间阈值（例如改为14天）
inactive_threshold = datetime.now(timezone.utc) - timedelta(days=14)
```

修改后需要重启应用才能生效。

## 注意事项

1. **数据备份**：在执行清理任务前，建议备份数据库，特别是生产环境
2. **执行时间**：建议在业务低峰期执行（如凌晨2点）
3. **监控**：定期检查清理任务的执行日志，确保任务正常运行
4. **性能影响**：清理大量数据时可能会对数据库性能产生短暂影响，建议在维护窗口执行

## 故障排查

### 任务未执行

1. 检查任务是否已创建并启用：
   ```sql
   SELECT * FROM scheduled_tasks WHERE task_name = '清理过期会话和黑名单';
   ```

2. 检查应用日志，查看是否有任务注册错误

3. 检查调度器是否正常运行

### 清理结果异常

1. 检查数据库连接是否正常
2. 检查表结构是否正确
3. 查看详细错误日志
