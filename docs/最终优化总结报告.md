## 三、代码优化成果（已完成）

### 3.1 提取公共函数

#### ✅ 新增 3 个公共函数

1. **`handleError(error, options)`** - 统一错误处理

   - 支持静默模式
   - 支持自定义错误处理函数
   - 自动显示错误消息

2. **`refreshCsrfTokenBeforeRequest(endpoint)`** - 统一 CSRF Token 刷新
   - 封装了 `refreshCsrfToken` 和 `ensureCsrfToken` 的调用
   - 支持指定刷新端点
   - 简化了代码

3. **`handleFileDownload(response, defaultFilename, onSuccess)`** - 统一文件下载处理
