# 清理脚本故障排查指南

## 问题：cleanup_expired_sessions.sql 执行失败

### 常见错误和解决方案

#### 错误1：表不存在

**错误信息**：
```
ERROR 1146 (42S02): Table 'platform.user_sessions' doesn't exist
```

**原因**：`user_sessions` 或 `token_blacklist` 表尚未创建

**解决方案**：

1. **检查表是否存在**：
   ```sql
   USE platform;
   SHOW TABLES LIKE 'user_sessions';
   SHOW TABLES LIKE 'token_blacklist';
   ```

2. **如果表不存在，创建表**：
   ```bash
   # 查看数据库迁移说明
   cat docs/数据库迁移说明.md
   
   # 或直接执行表创建脚本（如果存在）
   mysql -u root -p platform < scripts/create_session_tables.sql
   ```

3. **使用应用自动创建**：
   - 启动应用，SQLAlchemy 会自动创建表
   - 或手动执行表创建 SQL（参考 `docs/数据库迁移说明.md`）

#### 错误2：权限不足

**错误信息**：
```
ERROR 1142 (42000): DELETE command denied to user 'xxx'@'localhost' for table 'user_sessions'
```

**原因**：数据库用户没有 DELETE 或 UPDATE 权限

**解决方案**：

```sql
-- 授予权限（以 root 用户执行）
GRANT SELECT, INSERT, UPDATE, DELETE ON platform.user_sessions TO 'your_user'@'localhost';
GRANT SELECT, INSERT, UPDATE, DELETE ON platform.token_blacklist TO 'your_user'@'localhost';
FLUSH PRIVILEGES;
```

#### 错误3：SQL 语法错误

**错误信息**：
```
ERROR 1064 (42000): You have an error in your SQL syntax
```

**原因**：MySQL 版本不支持某些语法（如 IF 语句在存储过程外）

**解决方案**：

1. **使用简化版脚本**：
   ```bash
   mysql -u root -p platform < scripts/cleanup_expired_sessions_simple.sql
   ```

2. **检查 MySQL 版本**：
   ```sql
   SELECT VERSION();
   ```

3. **手动执行 SQL**：
   ```sql
   USE platform;
   
   -- 检查表是否存在
   SHOW TABLES LIKE 'user_sessions';
   
   -- 如果存在，执行清理
   DELETE FROM user_sessions 
   WHERE expires_at < DATE_SUB(NOW(), INTERVAL 30 DAY);
   ```

#### 错误4：数据库连接失败

**错误信息**：
```
ERROR 2002 (HY000): Can't connect to local MySQL server
```

**原因**：MySQL 服务未启动或连接配置错误

**解决方案**：

```bash
# 检查 MySQL 服务状态
sudo systemctl status mysql
# 或
sudo systemctl status mariadb

# 启动 MySQL 服务
sudo systemctl start mysql

# 测试连接
mysql -u root -p -e "SELECT 1;"
```

## 执行前检查清单

在执行清理脚本前，请确认：

- [ ] MySQL 服务正在运行
- [ ] 数据库 `platform` 存在
- [ ] 表 `user_sessions` 存在（如果不存在，可以跳过）
- [ ] 表 `token_blacklist` 存在（如果不存在，可以跳过）
- [ ] 数据库用户有足够的权限（SELECT, DELETE, UPDATE）
- [ ] MySQL 版本兼容（建议 5.7+）

## 手动执行清理

如果脚本执行失败，可以手动执行：

```sql
USE platform;

-- 1. 检查表是否存在
SHOW TABLES LIKE 'user_sessions';
SHOW TABLES LIKE 'token_blacklist';

-- 2. 查看当前数据量
SELECT COUNT(*) AS sessions_count FROM user_sessions;
SELECT COUNT(*) AS blacklist_count FROM token_blacklist;

-- 3. 查看过期数据
SELECT COUNT(*) AS expired_sessions 
FROM user_sessions 
WHERE expires_at < DATE_SUB(NOW(), INTERVAL 30 DAY);

SELECT COUNT(*) AS expired_blacklist 
FROM token_blacklist 
WHERE expires_at < DATE_SUB(NOW(), INTERVAL 30 DAY);

-- 4. 执行清理（谨慎操作）
-- 清理过期会话
DELETE FROM user_sessions 
WHERE expires_at < DATE_SUB(NOW(), INTERVAL 30 DAY);

-- 清理过期黑名单
DELETE FROM token_blacklist 
WHERE expires_at < DATE_SUB(NOW(), INTERVAL 30 DAY);

-- 标记非活跃会话
UPDATE user_sessions 
SET is_active = FALSE 
WHERE is_active = TRUE 
  AND last_activity < DATE_SUB(NOW(), INTERVAL 7 DAY);

-- 5. 查看清理结果
SELECT COUNT(*) AS remaining_sessions FROM user_sessions;
SELECT COUNT(*) AS remaining_blacklist FROM token_blacklist;
```

## 创建表（如果不存在）

如果表不存在，需要先创建表。参考 `docs/数据库迁移说明.md` 或执行：

```sql
USE platform;

-- 创建 user_sessions 表
CREATE TABLE IF NOT EXISTS `user_sessions` (
    `id` INT AUTO_INCREMENT PRIMARY KEY COMMENT '会话ID',
    `user_id` INT NOT NULL COMMENT '用户ID',
    `token_jti` VARCHAR(32) NOT NULL UNIQUE COMMENT 'JWT令牌ID（jti）',
    `ip_address` VARCHAR(50) DEFAULT NULL COMMENT '登录IP地址',
    `user_agent` VARCHAR(500) DEFAULT NULL COMMENT '用户代理（浏览器信息）',
    `device_info` VARCHAR(200) DEFAULT NULL COMMENT '设备信息（移动端/桌面端）',
    `location` VARCHAR(200) DEFAULT NULL COMMENT '登录位置（可选，通过IP解析）',
    `is_active` BOOLEAN NOT NULL DEFAULT TRUE COMMENT '是否活跃',
    `last_activity` DATETIME(6) NOT NULL DEFAULT CURRENT_TIMESTAMP(6) COMMENT '最后活动时间',
    `created_at` DATETIME(6) NOT NULL DEFAULT CURRENT_TIMESTAMP(6) COMMENT '创建时间（登录时间）',
    `expires_at` DATETIME(6) NOT NULL COMMENT '过期时间',
    INDEX `idx_session_user_active` (`user_id`, `is_active`),
    INDEX `idx_session_expires` (`expires_at`),
    INDEX `idx_user_id` (`user_id`),
    INDEX `idx_token_jti` (`token_jti`),
    INDEX `idx_ip_address` (`ip_address`),
    INDEX `idx_is_active` (`is_active`),
    INDEX `idx_last_activity` (`last_activity`)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COLLATE=utf8mb4_unicode_ci COMMENT='用户会话表';

-- 创建 token_blacklist 表
CREATE TABLE IF NOT EXISTS `token_blacklist` (
    `id` INT AUTO_INCREMENT PRIMARY KEY COMMENT '黑名单ID',
    `token_jti` VARCHAR(32) NOT NULL UNIQUE COMMENT 'JWT令牌ID（jti）',
    `user_id` INT NOT NULL COMMENT '用户ID',
    `revoked_at` DATETIME(6) NOT NULL DEFAULT CURRENT_TIMESTAMP(6) COMMENT '撤销时间',
    `expires_at` DATETIME(6) NOT NULL COMMENT 'Token过期时间',
    `reason` VARCHAR(200) DEFAULT NULL COMMENT '撤销原因（用户退出、强制退出等）',
    INDEX `idx_blacklist_user` (`user_id`),
    INDEX `idx_blacklist_expires` (`expires_at`),
    INDEX `idx_token_jti` (`token_jti`),
    INDEX `idx_revoked_at` (`revoked_at`)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COLLATE=utf8mb4_unicode_ci COMMENT='Token黑名单表';
```

## 验证清理结果

```sql
USE platform;

-- 查看清理后的数据量
SELECT 
    'user_sessions' AS table_name,
    COUNT(*) AS total_count,
    SUM(CASE WHEN expires_at < DATE_SUB(NOW(), INTERVAL 30 DAY) THEN 1 ELSE 0 END) AS expired_count,
    SUM(CASE WHEN is_active = FALSE THEN 1 ELSE 0 END) AS inactive_count
FROM user_sessions
UNION ALL
SELECT 
    'token_blacklist' AS table_name,
    COUNT(*) AS total_count,
    SUM(CASE WHEN expires_at < DATE_SUB(NOW(), INTERVAL 30 DAY) THEN 1 ELSE 0 END) AS expired_count,
    0 AS inactive_count
FROM token_blacklist;
```
