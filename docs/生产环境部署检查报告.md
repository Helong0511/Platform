### 📝 七、部署步骤验证

#### 7.1 环境准备
```bash
# 1. 创建项目目录
sudo mkdir -p /data/Platform
sudo chown -R www-data:www-data /data/Platform

# 2. 创建虚拟环境
cd /data/Platform
python3 -m venv venv
source venv/bin/activate
pip install --upgrade pip
pip install -r requirements.txt
deactivate

# 3. 配置环境变量
cp env.example .env
sudo chown www-data:www-data /data/Platform/.env
sudo chmod 640 /data/Platform/.env
# 编辑 .env 文件，设置所有必填配置项
```

#### 7.2 前端部署
```bash
cd /data/Platform/frontend
npm install
npm run build
# 构建产物在 frontend/dist 目录
```

#### 7.3 后端部署
```bash
# 1. 复制 systemd 服务文件
sudo cp systemd/Platform-backend.service /etc/systemd/system/

# 2. 设置日志目录权限
sudo mkdir -p /data/Platform/logs
sudo chown -R www-data:www-data /data/Platform/logs
sudo chmod 750 /data/Platform/logs

# 3. 重载 systemd
sudo systemctl daemon-reload

# 4. 启动服务
sudo systemctl start Platform-backend.service
sudo systemctl enable Platform-backend.service

# 5. 检查状态
sudo systemctl status Platform-backend.service
```

#### 7.4 Nginx 配置
```bash
# 1. 复制 Nginx 配置
sudo cp nginx/btfrx.online/nginx.conf /etc/nginx/sites-available/client.btfrx.online
sudo ln -s /etc/nginx/sites-available/client.btfrx.online /etc/nginx/sites-enabled/

# 2. 测试配置
sudo nginx -t

# 3. 重载 Nginx
sudo systemctl reload nginx
```
