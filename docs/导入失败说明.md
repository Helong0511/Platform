# Excel 导入失败说明

## "失败 1 条" 是什么意思？

"失败 1 条" 表示在导入 Excel 数据时，有 **1 行数据** 因为某种原因无法成功导入到数据库中。

## 如何查看失败原因？

### 方法一：查看错误通知（推荐）

当导入失败时，系统会显示一个**错误通知**，包含详细的失败原因：

- **标题**：`导入失败 X 条数据`
- **内容**：每行失败的具体原因，格式为 `第X行: 错误原因`

例如：
```
导入失败 1 条数据

第5行: 产品名称不能为空
```

### 方法二：查看浏览器控制台

1. 打开浏览器开发者工具（按 `F12`）
2. 切换到 "Console"（控制台）标签
3. 查找 `导入错误详情:` 的日志
4. 查看详细的错误信息

### 方法三：查看服务器日志

查看后端日志文件：`logs/app.log`，搜索 "导入统计" 或 "失败" 关键字。

## 常见的失败原因

### 1. **数据格式错误**
- **错误信息**：`数值字段格式错误`
- **原因**：Excel 中的数字字段包含了非数字字符
- **解决方法**：检查 Excel 文件，确保数字字段只包含数字

### 2. **必填字段为空**
- **错误信息**：`产品名称不能为空` 或 `日期格式无效`
- **原因**：必填字段（如产品名称、日期）为空
- **解决方法**：检查 Excel 文件，确保所有必填字段都有值

### 3. **数值为负数**
- **错误信息**：`请求数、匹配数、展示数和点击数不能为负数` 或 `eCPM和收益不能为负数`
- **原因**：某些数值字段包含了负数
- **解决方法**：检查 Excel 文件，确保数值字段都是非负数

### 4. **产品不存在**
- **错误信息**：`产品名称 'XXX' 不存在`
- **原因**：Excel 中的产品名称在系统中不存在
- **解决方法**：
  - 检查产品名称是否正确
  - 或者先在系统中创建该产品

### 5. **日期格式错误**
- **错误信息**：`日期格式无效，应为YYYY-MM-DD或YYYY/MM/D`
- **原因**：日期格式不正确
- **解决方法**：确保日期格式为 `YYYY-MM-DD` 或 `YYYY/MM/DD`

### 6. **数据验证失败**
- **错误信息**：`数据验证失败: XXX`
- **原因**：数据不符合业务规则
- **解决方法**：根据具体错误信息修正数据

## 导入结果说明

导入完成后，系统会显示导入结果，包括：

- **成功 X 条**：成功导入的数据行数
- **新增 X 条**：新创建的数据记录数
- **更新 X 条**：更新已存在的数据记录数
- **失败 X 条**：导入失败的数据行数
- **跳过重复 X 条**：Excel 内部重复的数据行数（只保留最后一行）

## 如何处理失败的数据？

1. **查看错误详情**：根据错误通知或日志，了解失败原因
2. **修正 Excel 文件**：根据错误信息修正对应的数据行
3. **重新导入**：修正后重新上传 Excel 文件

## 注意事项

- 失败的数据**不会**被导入到数据库中
- 成功的数据会正常导入，不受失败数据影响
- 如果有多行失败，错误通知会显示所有失败行的详细信息
- 建议在导入前先检查 Excel 文件的数据完整性

## 示例

假设导入结果如下：

```
导入完成: 成功 99 条，新增 50 条，更新 49 条，失败 1 条
```

这表示：
- 总共处理了 100 行数据（99 成功 + 1 失败）
- 其中 50 条是新数据，49 条是更新已有数据
- 有 1 条数据导入失败

查看错误通知，可能会看到：

```
导入失败 1 条数据

第25行: 产品名称不能为空
```

这说明第 25 行的数据因为"产品名称为空"而导入失败。

## 需要帮助？

如果遇到问题，请：
1. 查看错误通知中的详细错误信息
2. 检查浏览器控制台的日志
3. 查看服务器日志文件
4. 根据错误信息修正 Excel 文件后重新导入
