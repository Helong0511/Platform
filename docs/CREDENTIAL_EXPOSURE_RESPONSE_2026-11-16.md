# 公开仓库环境凭据暴露处置（2026-11-16）

## 发现

公开仓库默认分支曾跟踪根目录 `.env`。该文件包含非空数据库 DSN、应用签名密钥、管理员口令、Telegram Bot Token、追踪密钥和多个第三方 API 认证配置。源码配置还曾包含可连接的 MySQL 默认 DSN。

本文件不复制任何凭据值。

## 当前修复

- 删除被 Git 跟踪的根目录 `.env`。
- 将根目录 `.env` 纳入忽略规则，仅允许提交无凭据的 `.env.example`。
- 新增配置模板，所有敏感项均使用占位符。
- 删除源码中的 MySQL 用户名/密码默认值；数据库 DSN 必须由环境显式注入。
- 新增数据库 DSN 缺失、空白、显式注入测试。

## 必须立即执行的凭据轮换

由于仓库公开且 Git 历史可能保留旧内容，以下凭据全部按已泄露处理：

1. MySQL 账号口令；核验授权范围、来源 IP、异常登录。
2. Redis 口令（若曾启用）。
3. 应用/JWT 签名密钥与追踪主密钥；评估现有会话、令牌及历史追踪数据失效影响。
4. 首次管理员口令；检查管理员登录记录和异常账号。
5. Telegram Bot Token；从 Bot 官方管理渠道吊销旧 Token。
6. 所有第三方广告平台 API Key、Secret、Token、用户名/密码和私钥。
7. 其它用于认证、签名或加密的非空密钥。

轮换应通过各服务官方控制台/管理渠道执行，并记录完成时间、受影响服务和验证结果。代码提交不会自动撤销凭据。
