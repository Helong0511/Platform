# Cron 表达式说明

## 📖 什么是 Cron 表达式

Cron 表达式是一种用于配置定时任务执行时间的字符串格式。它由 5 个或 6 个字段组成，用空格分隔，分别表示：秒、分、时、日、月、星期（可选）。

## 📋 Cron 表达式格式

### 标准格式（5 字段）

```
分 时 日 月 星期
```

### 扩展格式（6 字段，包含秒）

```
秒 分 时 日 月 星期
```

**注意**：APScheduler 使用 5 字段格式（不包含秒），格式为：`分 时 日 月 星期`

## 🔢 字段说明

| 字段 | 允许值 | 特殊字符 | 说明 |
|------|--------|----------|------|
| 分 | 0-59 | `*` `,` `-` `/` | 分钟 |
| 时 | 0-23 | `*` `,` `-` `/` | 小时 |
| 日 | 1-31 | `*` `,` `-` `/` `?` `L` `W` | 日期 |
| 月 | 1-12 或 JAN-DEC | `*` `,` `-` `/` | 月份 |
| 星期 | 0-7 或 SUN-SAT | `*` `,` `-` `/` `?` `L` `#` | 星期（0 和 7 都表示星期日） |

## 🎯 特殊字符说明

- `*`：匹配所有可能的值
- `,`：指定多个值（例如：`1,3,5`）
- `-`：指定范围（例如：`1-5`）
- `/`：指定步长（例如：`*/5` 表示每 5 个单位）
- `?`：不指定值（仅用于日期和星期字段）
- `L`：最后（Last），仅用于日期和星期字段
- `W`：工作日（Weekday），仅用于日期字段
- `#`：第几个（例如：`MON#2` 表示第二个星期一），仅用于星期字段

## 📝 常用 Cron 表达式示例

### 每分钟执行

```
* * * * *
```
**说明**：每分钟的第 0 秒执行

### 每 5 分钟执行

```
*/5 * * * *
```
**说明**：每 5 分钟执行一次（0:00, 0:05, 0:10, 0:15...）

### 每 10 分钟执行

```
*/10 * * * *
```
**说明**：每 10 分钟执行一次（0:00, 0:10, 0:20, 0:30...）

### 每 30 分钟执行

```
*/30 * * * *
```
**说明**：每 30 分钟执行一次（0:00, 0:30, 1:00, 1:30...）

### 每小时执行

```
0 * * * *
```
**说明**：每小时的第 0 分钟执行（0:00, 1:00, 2:00...）

### 每天固定时间执行

#### 每天凌晨 0 点执行

```
0 0 * * *
```
**说明**：每天 00:00 执行

#### 每天凌晨 2 点执行

```
0 2 * * *
```
**说明**：每天 02:00 执行

#### 每天中午 12 点执行

```
0 12 * * *
```
**说明**：每天 12:00 执行

#### 每天下午 3 点 30 分执行

```
30 15 * * *
```
**说明**：每天 15:30 执行

#### 每天多个时间点执行

```
0 9,12,18 * * *
```
**说明**：每天 09:00、12:00、18:00 执行

### 每周执行

#### 每周一凌晨 0 点执行

```
0 0 * * 1
```
或
```
0 0 * * MON
```
**说明**：每周一 00:00 执行

#### 每周五下午 5 点执行

```
0 17 * * 5
```
或
```
0 17 * * FRI
```
**说明**：每周五 17:00 执行

#### 每周一、三、五执行

```
0 0 * * 1,3,5
```
或
```
0 0 * * MON,WED,FRI
```
**说明**：每周一、三、五 00:00 执行

### 每月执行

#### 每月 1 号凌晨 0 点执行

```
0 0 1 * *
```
**说明**：每月 1 号 00:00 执行

#### 每月 15 号上午 10 点执行

```
0 10 15 * *
```
**说明**：每月 15 号 10:00 执行

#### 每月最后一天执行

```
0 0 L * *
```
**说明**：每月最后一天 00:00 执行

### 每年执行

#### 每年 1 月 1 号凌晨 0 点执行

```
0 0 1 1 *
```
**说明**：每年 1 月 1 号 00:00 执行

#### 每年 12 月 31 号执行

```
0 0 31 12 *
```
**说明**：每年 12 月 31 号 00:00 执行

### 工作日执行

#### 每个工作日上午 9 点执行

```
0 9 * * 1-5
```
或
```
0 9 * * MON-FRI
```
**说明**：周一到周五 09:00 执行

#### 每个周末执行

```
0 0 * * 0,6
```
或
```
0 0 * * SUN,SAT
```
**说明**：周六和周日 00:00 执行

### 复杂时间组合

#### 工作日上午 9 点和下午 5 点执行

```
0 9,17 * * 1-5
```
**说明**：周一到周五的 09:00 和 17:00 执行

#### 每月 1 号和 15 号执行

```
0 0 1,15 * *
```
**说明**：每月 1 号和 15 号 00:00 执行

#### 每季度执行（1、4、7、10 月的 1 号）

```
0 0 1 1,4,7,10 *
```
**说明**：每季度第一天 00:00 执行

#### 每小时的 0 分和 30 分执行

```
0,30 * * * *
```
**说明**：每小时的 00 分和 30 分执行（例如：00:00, 00:30, 01:00, 01:30...）

#### 每天上午 8 点到下午 6 点，每小时执行

```
0 8-18 * * *
```
**说明**：每天 08:00 到 18:00，每小时执行一次

#### 每天上午 8 点到下午 6 点，每 2 小时执行

```
0 8-18/2 * * *
```
**说明**：每天 08:00, 10:00, 12:00, 14:00, 16:00, 18:00 执行

## 🎨 实际应用场景示例

### 数据备份任务

#### 每天凌晨 2 点备份

```
0 2 * * *
```
**说明**：系统负载较低时进行备份

#### 每周日凌晨 3 点完整备份

```
0 3 * * 0
```
**说明**：周末进行完整备份

### 数据清理任务

#### 每天凌晨 1 点清理临时文件

```
0 1 * * *
```
**说明**：每天清理临时数据

#### 每月 1 号凌晨 4 点清理过期数据

```
0 4 1 * *
```
**说明**：每月清理一次过期数据

### 数据同步任务

#### 每 5 分钟同步一次

```
*/5 * * * *
```
**说明**：高频数据同步

#### 每 30 分钟同步一次

```
*/30 * * * *
```
**说明**：中频数据同步

#### 每小时同步一次

```
0 * * * *
```
**说明**：低频数据同步

### 报表生成任务

#### 每天上午 9 点生成日报

```
0 9 * * *
```
**说明**：工作日生成前一天的报表

#### 每周一上午 9 点生成周报

```
0 9 * * 1
```
**说明**：每周一生成上周的报表

#### 每月 1 号上午 10 点生成月报

```
0 10 1 * *
```
**说明**：每月 1 号生成上月的报表

### 监控和检查任务

#### 每 10 分钟检查一次系统状态

```
*/10 * * * *
```
**说明**：高频监控

#### 工作日上午 9 点到下午 6 点，每 30 分钟检查一次

```
*/30 9-18 * * 1-5
```
**说明**：工作时间内的监控

## ⚠️ 注意事项

1. **时区设置**：本系统使用 `Asia/Shanghai`（中国时区，UTC+8）
   - Cron 表达式中的时间都是基于中国时区
   - 例如：`0 2 * * *` 表示每天北京时间 02:00 执行

2. **日期和星期冲突**：
   - 如果同时指定了日期和星期，两个条件都必须满足
   - 建议使用 `?` 来避免冲突：
     - 指定日期时，星期字段使用 `?`：`0 0 1 * ?`
     - 指定星期时，日期字段使用 `?`：`0 0 ? * 1`

3. **月份和星期的英文缩写**：
   - 月份：JAN, FEB, MAR, APR, MAY, JUN, JUL, AUG, SEP, OCT, NOV, DEC
   - 星期：SUN, MON, TUE, WED, THU, FRI, SAT

4. **步长表达式**：
   - `*/5` 表示每 5 个单位执行一次
   - `0-30/5` 表示从 0 到 30，每 5 个单位执行一次（0, 5, 10, 15, 20, 25, 30）

5. **最后一天**：
   - `L` 表示月份的最后一天
   - `L-1` 表示倒数第二天
   - `15W` 表示最接近 15 号的工作日
