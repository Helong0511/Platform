## 一、数据库层面优化

### 1.1 索引优化策略

#### ✅ 已优化
- 添加了唯一约束和复合索引
- 清理了冗余索引

#### 🔄 进一步优化

**1. 分区表策略（大数据量场景）**

```sql
-- 为 ad_data 表按日期分区（MySQL 5.7+）
-- 每月一个分区，提升查询性能
ALTER TABLE `ad_data` 
PARTITION BY RANGE (TO_DAYS(`date`)) (
    PARTITION p202401 VALUES LESS THAN (TO_DAYS('2024-02-01')),
    PARTITION p202402 VALUES LESS THAN (TO_DAYS('2024-03-01')),
    -- ... 继续添加分区
    PARTITION p_future VALUES LESS THAN MAXVALUE
);
```

**优势：**
- 查询时只扫描相关分区
- 删除旧数据时直接删除分区（秒级）
- 提升查询性能 3-5 倍

**2. 覆盖索引优化**

```sql
-- 为常见查询添加覆盖索引
-- 查询：SELECT date, product_id, request_count, match_count FROM ad_data WHERE date >= ? AND date <= ?
ALTER TABLE `ad_data` ADD INDEX `idx_ad_data_date_product_covering` 
    (`date`, `product_id`, `request_count`, `match_count`, `display_count`, `click_count`);
```

**3. 函数索引（MySQL 8.0+）**

```sql
-- 如果必须使用日期函数，添加函数索引
ALTER TABLE `ad_data` ADD INDEX `idx_ad_data_date_func` ((DATE(`date`)));
```

### 1.2 数据归档策略

**问题：** `ad_data` 表会无限增长，影响查询性能

**解决方案：**

```sql
-- 创建归档表
CREATE TABLE `ad_data_archive` LIKE `ad_data`;
ALTER TABLE `ad_data_archive` ENGINE=ARCHIVE;  -- 使用归档引擎（压缩存储）

-- 定期归档脚本（每月执行一次）
-- 归档 6 个月前的数据
INSERT INTO `ad_data_archive` 
SELECT * FROM `ad_data` 
WHERE `date` < DATE_SUB(CURDATE(), INTERVAL 6 MONTH);

DELETE FROM `ad_data` 
WHERE `date` < DATE_SUB(CURDATE(), INTERVAL 6 MONTH);
```

**代码实现：** 创建定时任务自动归档

## 二、代码层面优化

### 2.1 N+1 查询优化

#### ✅ 已优化
- 部分查询使用了 `selectinload`

#### 🔄 进一步优化

**1. 批量预加载关联数据**

```python
# 优化前（N+1 查询）
products = await db.execute(select(Product))
for product in products:
    client = await db.get(Client, product.client_id)  # N+1 问题

# 优化后（批量查询）
from sqlalchemy.orm import selectinload
products = await db.execute(
    select(Product)
    .options(selectinload(Product.client))
)
# 所有关联数据一次性加载
```

**2. 批量操作优化**

```python
# 优化前（逐条插入）
for item in data_list:
    db.add(AdData(...))
    await db.commit()  # 每次提交

# 优化后（批量插入）
from sqlalchemy.dialects.mysql import insert
# 使用 bulk_insert_mappings 批量插入
await db.execute(
    insert(AdData).values([...])  # 批量数据
)
await db.commit()  # 一次性提交
```

### 2.2 缓存策略

#### ✅ 已有
- 前端有简单的内存缓存（客户详情）
- Redis 用于限流和 CSRF

#### 🔄 进一步优化

**1. 后端查询缓存（Redis）**

```python
# app/core/cache.py
from app.core.redis_client import get_redis_client
import json
import hashlib

async def get_cached_query(key: str, ttl: int = 300):
    """获取缓存的查询结果"""
    redis = await get_redis_client()
    if not redis:
        return None
    
    cached = await redis.get(f"query_cache:{key}")
    if cached:
        return json.loads(cached)
    return None

async def set_cached_query(key: str, value: any, ttl: int = 300):
    """设置查询结果缓存"""
    redis = await get_redis_client()
    if redis:
        await redis.setex(
            f"query_cache:{key}",
            ttl,
            json.dumps(value, default=str)
        )

# 使用示例
@router.get("/stats")
async def get_dashboard_stats(...):
    # 生成缓存键
    cache_key = hashlib.md5(
        f"stats:{period}:{current_user.id}".encode()
    ).hexdigest()
    
    # 尝试从缓存获取
    cached = await get_cached_query(cache_key, ttl=60)
    if cached:
        return cached
    
    # 执行查询
    result = await execute_query(...)
    
    # 缓存结果
    await set_cached_query(cache_key, result, ttl=60)
    return result
```

**2. 热点数据缓存**

```python
# 缓存产品列表、客户列表等热点数据
# 更新时清除缓存
async def invalidate_cache(pattern: str):
    """清除匹配模式的缓存"""
    redis = await get_redis_client()
    if redis:
        keys = await redis.keys(f"query_cache:{pattern}*")
        if keys:
            await redis.delete(*keys)
```

### 2.3 异步批量处理

**优化 Excel 导入：**

```python
# 当前：逐条处理
# 优化：批量处理
async def batch_process_ad_data(
    data_list: list[dict],
    db: AsyncSession,
    batch_size: int = 1000
):
    """批量处理广告数据"""
    for i in range(0, len(data_list), batch_size):
        batch = data_list[i:i + batch_size]
        
        # 批量查询已存在的记录
        date_product_pairs = [(d['date'], d['product_id']) for d in batch]
        existing = await batch_query_existing(date_product_pairs, db)
        
        # 批量更新/插入
        updates = []
        inserts = []
        for item in batch:
            key = (item['date'], item['product_id'])
            if key in existing:
                updates.append(item)
            else:
                inserts.append(item)
        
        # 批量执行
        if updates:
            await batch_update(updates, db)
        if inserts:
            await batch_insert(inserts, db)
        
        await db.commit()
```

### 2.4 查询优化模式

**1. 使用 EXISTS 替代 COUNT**

```python
# 优化前
count = await db.execute(select(func.count(Product.id)).where(...))
if count.scalar() > 0:
    ...

# 优化后
exists = await db.execute(
    select(1).where(Product.id.in_(...)).limit(1)

if exists.first():
    ...
```

```python
# 优化前（OFFSET 分页，大数据量慢）
```

### 2.5 日期查询统一优化

**创建工具函数：**

```python
# app/core/query_utils.py
from datetime import date, datetime
from sqlalchemy import Column

def date_range_condition(
    column: Column,
    start_date: date | None,
    end_date: date | None
):
    """生成日期范围查询条件（优化版本）"""
    conditions = []
    if start_date:
        conditions.append(
            column >= datetime.combine(start_date, datetime.min.time())
        )
    if end_date:
        conditions.append(
            column <= datetime.combine(end_date, datetime.max.time())
        )
    return and_(*conditions) if conditions else None

# 使用示例
query = query.where(
    date_range_condition(AdData.date, start_date, end_date)
)
```

```python
# 监控数据库查询时间
import time
from functools import wraps

def monitor_query_time(func):
    @wraps(func)
    async def wrapper(*args, **kwargs):
        start = time.time()
        result = await func(*args, **kwargs)
        duration = time.time() - start
        if duration > 1.0:  # 超过 1 秒记录
            logger.warning(f"Slow query: {func.__name__} took {duration:.2f}s")
        return result
    return wrapper
```

```python
# 使用生成器流式导出，避免内存溢出
async def stream_export_ad_data(query, batch_size=1000):
    """流式导出广告数据"""
    offset = 0
    while True:
        batch = await db.execute(
            query.offset(offset).limit(batch_size)
        )
        rows = batch.all()
        if not rows:
            break
        yield rows
        offset += batch_size
```
