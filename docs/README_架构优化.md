## 🔑 核心功能

### 装饰器
- `@require_admin` - 管理员权限检查
- `@require_roles` - 特定角色检查
- `@check_resource_owner` - 资源所有权检查
- `@validate_pagination` - 分页参数验证

### 查询构建器
- `QueryBuilder` - 链式查询构建
- `build_query` - 快速构建查询
- 支持过滤、搜索、排序、分页、关联预加载

### 响应格式
- `create_success_response` - 创建成功响应
- `create_error_response` - 创建错误响应
- `create_paginated_response` - 创建分页响应

### 依赖注入
- `CurrentAdminDep` - 管理员用户依赖
- `DbAndUserDep` - 数据库和用户组合依赖
- `DbAndAdminDep` - 数据库和管理员组合依赖

## 📊 优化成果
