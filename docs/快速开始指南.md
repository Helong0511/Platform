# 快速开始指南

## 功能改进快速部署

本文档提供快速部署所有新功能的步骤指南。

## 前置要求

1. Python 3.10+
2. MySQL 5.7.6+（支持ngram解析器）
3. Redis（可选但推荐，生产环境强烈建议）

## 部署步骤

### 1. 更新依赖

```bash
pip install -r requirements.txt
```

主要新增依赖：
- `redis>=5.0.0` - Redis客户端（支持异步）

### 2. 配置环境变量

编辑 `.env` 文件，添加以下配置：

```env
# Redis配置（可选但推荐）
REDIS_HOST=redis
REDIS_PORT=6379
REDIS_DB=0
REDIS_PASSWORD=your-redis-password

# CSRF配置（默认启用）
ENABLE_CSRF=true
CSRF_TOKEN_EXPIRE_SECONDS=3600
```

### 3. 执行数据库迁移

#### 3.1 添加全文搜索索引

```bash
mysql -u root -p platform < scripts/add_fulltext_indexes.sql
```

或者在MySQL客户端中执行：

```sql
USE platform;
SOURCE scripts/add_fulltext_indexes.sql;
```

**注意：**
- 如果MySQL版本不支持ngram解析器（< 5.7.6），需要修改SQL脚本，移除 `WITH PARSER ngram` 部分
- 如果表已有大量数据，索引创建可能需要一些时间

#### 3.2 会话管理表

会话管理表会在应用启动时自动创建，无需手动执行SQL。

如果需要手动创建，参考 `docs/数据库迁移说明.md`。

### 4. 启动Redis（如果配置了）

#### 使用系统服务：

```bash
# Ubuntu/Debian
sudo systemctl start redis-server
sudo systemctl enable redis-server

# 设置密码（编辑配置文件）
sudo nano /etc/redis/redis.conf
# 找到 requirepass 行，取消注释并设置密码
# requirepass your-redis-password

# 重启 Redis
sudo systemctl restart redis-server
```

#### 或直接运行：

```bash
redis-server --requirepass your-redis-password
```

### 5. 重启应用

```bash
# 开发环境
python -m uvicorn app.main:app --reload

# 生产环境
gunicorn app.main:app -w 3 -k uvicorn.workers.UvicornWorker
```

### 6. 验证功能

#### 6.1 验证CSRF防护

1. 打开浏览器开发者工具
2. 访问任意页面
3. 检查响应头中是否有 `X-CSRF-Token`
4. 检查后续POST/PUT/DELETE请求是否包含 `X-CSRF-Token` 头

#### 6.2 验证Redis连接

查看应用日志，应该看到：
```
Redis连接成功: redis:6379/0
```

如果未配置Redis，会看到：
```
Redis未配置，使用内存存储
```

#### 6.3 验证全文搜索

1. 访问用户管理页面
2. 在搜索框输入关键词
3. 检查搜索结果是否正确
4. 查看数据库日志，确认使用了全文索引（如果可用）

#### 6.4 验证会话管理

1. 登录系统
2. 访问 `/api/v1/sessions/me/sessions`（需要认证）
3. 应该能看到当前用户的活跃会话列表

## 功能说明

### CSRF防护

- **状态**：默认启用
- **配置**：`ENABLE_CSRF=true/false`
- **行为**：
  - GET请求自动生成CSRF令牌
  - POST/PUT/PATCH/DELETE请求验证CSRF令牌
  - 登录/登出接口自动跳过CSRF检查

### Redis限流

- **状态**：如果配置了Redis，自动使用
- **配置**：`REDIS_HOST`、`REDIS_PORT`、`REDIS_DB`、`REDIS_PASSWORD`
- **行为**：
  - 如果Redis可用，使用Redis存储限流信息
  - 如果Redis不可用，自动回退到内存存储
  - 多进程环境下，Redis确保限流一致性

### 会话管理

- **状态**：自动启用
- **功能**：
  - 登录时自动记录会话信息
  - 退出登录时自动撤销会话
  - 用户可查看和管理自己的会话
  - 管理员可管理所有用户的会话

### 全文搜索

- **状态**：执行数据库迁移后自动启用
- **行为**：
  - 优先使用全文索引（如果可用）
  - 如果索引不可用，自动回退到LIKE查询
  - 支持中文搜索（ngram解析器）

### 虚拟滚动

- **状态**：组件已创建，需要手动集成
- **使用**：参考 `README_虚拟滚动使用说明.md`

## 故障排查

### 全文索引创建失败

**错误**：`You have an error in your SQL syntax`

**原因**：MySQL版本不支持ngram解析器

**解决**：修改 `scripts/add_fulltext_indexes.sql`，移除所有 `WITH PARSER ngram` 部分

### Redis连接失败

**错误**：`Redis连接失败`

**原因**：Redis未启动或配置错误

**解决**：
1. 检查Redis是否运行：`redis-cli ping`
2. 检查环境变量配置
3. 如果不需要Redis，可以不配置（将使用内存存储）

### CSRF令牌验证失败

**错误**：`CSRF令牌缺失` 或 `CSRF令牌验证失败`

**原因**：前端未正确发送CSRF令牌

**解决**：
1. 检查前端是否正确处理CSRF令牌
2. 检查浏览器控制台是否有错误
3. 尝试刷新页面重新获取CSRF令牌

### 会话管理表未创建

**错误**：`Table 'platform.user_sessions' doesn't exist`

**原因**：应用启动时未正确导入模型

**解决**：
1. 检查 `app/models/__init__.py` 是否正确导入所有模型
2. 检查 `app/main.py` 是否正确导入模型
3. 手动执行SQL创建表（参考 `docs/数据库迁移说明.md`）

## 性能优化建议

1. **生产环境配置Redis**：
   - 确保限流在多进程环境下一致
   - 提升CSRF令牌存储性能

2. **定期清理过期数据**：
   - 创建定时任务清理过期会话
   - 清理过期黑名单记录

3. **监控全文索引性能**：
   - 定期检查索引使用情况
   - 根据实际使用情况调整索引策略
