## 🎨 装饰器使用

### @require_admin - 管理员权限检查

```python
from app.core.decorators import require_admin

@router.get("/admin/users")
@require_admin
async def get_users(current_user: User = Depends(get_current_user)):
    # 只有管理员可以访问
    pass
```

### @require_roles - 特定角色检查

```python
from app.core.decorators import require_roles
from app.models.models import UserRole

@router.get("/client/dashboard")
@require_roles(UserRole.CLIENT, UserRole.ADMIN)
async def get_dashboard(current_user: User = Depends(get_current_user)):
    # 只有客户或管理员可以访问
    pass
```

### @validate_pagination - 分页参数验证

```python
from app.core.decorators import validate_pagination

@router.get("/items")
@validate_pagination(max_page_size=50)
async def get_items(
    page: int = Query(1, ge=1),
    page_size: int = Query(20, ge=1, le=50)
):
    # 分页参数已自动验证
    pass
```

## 🔍 查询构建器使用

### 基础查询

```python
from app.core.query_builder import build_query

# 简单查询
builder = build_query(
    db=db,
    model=User,
    filters={"is_active": True},
    order_by_field="created_at",
    page=1,
    page_size=20
)
users, total = await builder.paginated(1, 20)
```

### 搜索查询

```python
# 带搜索的查询
builder = build_query(
    db=db,
    model=User,
    filters={"is_active": True},
    search_fields=["username", "email", "full_name"],
    search_keyword=keyword,
    order_by_field="created_at",
    page=page,
    page_size=page_size
)
users, total = await builder.paginated(page, page_size)
```

### 关联预加载

```python
# 预加载关联关系（避免N+1查询）
builder = build_query(
    db=db,
    model=Product,
    relations=["client", "creator"],  # 预加载关联
    order_by_field="created_at"
)
products = await builder.all()
```

### 链式查询

```python
from app.core.query_builder import QueryBuilder

builder = QueryBuilder(db, User)
users = await (builder
    .base()
    .filter(is_active=True)
    .search(["username", "email"], keyword)
    .order_by("created_at")
    .paginate(page, page_size)
    .all())
```

## 🏗️ 服务层和仓储层使用

### 服务层示例

```python
from app.services.base_service import BaseService
from app.models.models import User

class UserService(BaseService[User]):
    def __init__(self, db: AsyncSession):
        super().__init__(db, User)
    
    async def get_user_by_id(
        self,
        user_id: int,
        current_user: User
    ) -> User:
        # 权限检查
        self.require_owner_or_admin(current_user, user_id)
        
        # 通过仓储层获取数据
        user = await self.repository.get_by_id(
            user_id,
            load_relations=["client"]  # 预加载关联
        )
        
        if not user:
            raise_api_exception(ErrorCode.USER_NOT_FOUND, ...)
        
        return user
    
    async def get_users_paginated(
        self,
        page: int = 1,
        page_size: int = 20,
        search: Optional[str] = None,
        current_user: User = None
    ) -> Tuple[List[User], int]:
        # 构建过滤条件
        filters = {}
        if current_user and current_user.role != UserRole.ADMIN:
            filters["created_by"] = current_user.id
        
        # 使用仓储层分页查询
        return await self.repository.paginated(
            page=page,
            page_size=page_size,
            filters=filters,
            search_fields=["username", "email"],
            search_keyword=search,
            order_by_field="created_at"
        )
```

### 仓储层示例

```python
from app.repositories.base_repository import BaseRepository
from app.models.models import Product

class ProductRepository(BaseRepository[Product]):
    def __init__(self, db: AsyncSession):
        super().__init__(db, Product)
    
    async def find_by_client_id(
        self,
        client_id: int,
        load_relations: Optional[List[str]] = None
    ) -> List[Product]:
        """根据客户ID查找产品"""
        return await self.find_all_by_field(
            "client_id",
            client_id,
            load_relations=load_relations
        )
```

## 🔄 完整示例

### Endpoint 重构示例

**重构前**：
```python
@router.get("/users")
async def get_users(
    page: int = Query(1, ge=1),
    page_size: int = Query(20, ge=1, le=100),
    search: Optional[str] = None,
    db: AsyncSession = Depends(get_db),
    current_user: User = Depends(get_current_user)
):
    # 权限检查
    if current_user.role != UserRole.ADMIN:
        raise_api_exception(ErrorCode.FORBIDDEN, ...)
    
    # 构建查询
    query = select(User)
    if search:
        query = query.where(or_(
            User.username.like(f"%{search}%"),
            User.email.like(f"%{search}%")
        ))
    query = query.order_by(User.created_at.desc())
    
    # 分页
    total_query = select(func.count(User.id))
    total_result = await db.execute(total_query)
    total = total_result.scalar() or 0
    
    query = query.offset((page - 1) * page_size).limit(page_size)
    result = await db.execute(query)
    users = result.scalars().all()
    
    return ResponseBaseSchema.success(data=users)
```

**重构后**：
```python
from app.core.decorators import require_admin, validate_pagination
from app.core.dependencies import UserServiceDep
from app.core.response import create_paginated_response

@router.get("/users")
@require_admin
@validate_pagination(max_page_size=100)
async def get_users(
    page: int = Query(1, ge=1),
    page_size: int = Query(20, ge=1, le=100),
    search: Optional[str] = None,
    user_service: UserServiceDep,
    current_user: User = Depends(get_current_user)
):
    # 业务逻辑在服务层
    users, total = await user_service.get_users_paginated(
        page=page,
        page_size=page_size,
        search=search,
        current_user=current_user
    )
    
    return create_paginated_response(
        items=users,
        total=total,
        page=page,
        page_size=page_size
    )
```

## 📝 最佳实践

1. **使用装饰器进行权限检查**，而不是在endpoint中手动检查
2. **使用查询构建器**，而不是直接构建SQL查询
3. **使用统一响应格式**，确保API一致性
4. **业务逻辑在服务层**，endpoint只负责HTTP处理
5. **数据访问在仓储层**，服务层通过仓储层访问数据
6. **使用组合依赖项**，简化endpoint参数
