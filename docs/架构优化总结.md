#### 装饰器
```python
from app.core.decorators import require_admin, validate_pagination

@router.get("/admin/users")
@require_admin
@validate_pagination(max_page_size=100)
async def get_users(...):
    pass
```

#### 查询构建器
```python
from app.core.query_builder import build_query

builder = build_query(
    db=db,
    model=User,
    filters={"is_active": True},
    search_fields=["username", "email"],
    search_keyword=keyword,
    page=page,
    page_size=page_size
)
users, total = await builder.paginated(page, page_size)
```

#### 统一响应格式
```python
from app.core.response import create_success_response, create_paginated_response

return create_success_response(data=user, message="查询成功")
return create_paginated_response(items=users, total=total, page=page, page_size=page_size)
```
