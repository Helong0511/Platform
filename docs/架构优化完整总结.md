### 1. 代码组织
- **职责分离**：endpoint只负责HTTP处理，业务逻辑在服务层
- **代码复用**：业务逻辑可在多个endpoint中复用
- **易于测试**：服务层方法可以直接测试
- **易于维护**：业务逻辑集中管理

- **缓存策略**：提供缓存抽象层
- **查询优化**：使用selectinload/joinedload优化关联查询

- **依赖注入**：统一管理依赖
- **抽象接口**：缓存、查询等提供抽象接口

## 🚀 使用示例

### 示例1：查询操作
```python
@router.get("/users/{user_id}")
async def get_user(
    user_id: int,
    user_service: UserService = Depends(get_user_service),
    current_user: User = Depends(get_current_user)
):
    user = await user_service.get_user_by_id(user_id, current_user)
    return ResponseBaseSchema.success(data=UserResponse.model_validate(user))
```

### 示例2：创建操作
```python
@router.post("/users")
async def create_user(
    user_in: UserCreate,

    current_user: User = Depends(require_admin)
```
