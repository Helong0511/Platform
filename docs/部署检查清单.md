- [ ] 验证归档任务已添加

### 2. 环境变量配置 ✅

- [ ] `PRODUCTION_ENV=production`
- [ ] `SECRET_KEY` 已设置（至少32字符）
- [ ] `DATABASE_URL` 已设置（生产环境密码）
- [ ] `DB_POOL_SIZE` 已配置（建议 15-20）
- [ ] `DB_MAX_OVERFLOW` 已配置（建议 10-15）
- [ ] `REDIS_URL` 已配置（如果使用 Redis）
- [ ] `BACKEND_CORS_ORIGINS` 已设置（生产环境必须）

### 3. MySQL 配置优化 ✅

- [ ] `max_connections` 已调整（建议 200+）
- [ ] `innodb_buffer_pool_size` 已设置（建议 50-70% 内存）
- [ ] `slow_query_log` 已启用
- [ ] `long_query_time` 已设置（建议 1 秒）

### 4. 代码验证 ✅

- [ ] 所有代码已通过 Linter 检查
- [ ] 无语法错误
- [ ] 所有导入正确
- [ ] 测试环境验证通过

### 5. 性能监控 ✅

- [ ] 性能监控中间件已启用
- [ ] 连接池监控脚本可用
- [ ] 慢查询日志已配置

## 🚀 部署步骤

### 1. 备份数据库

```bash
mysqldump -u root -p platform > platform_backup_$(date +%Y%m%d_%H%M%S).sql
```

### 2. 执行优化 SQL

```bash
# 覆盖索引
mysql -u root -p platform < scripts/add_covering_indexes.sql

# 归档任务
mysql -u root -p platform < scripts/add_archive_task.sql
```

### 3. 验证优化

```bash
# 运行性能测试
python scripts/performance_test.py

# 监控连接池
python scripts/monitor_db_pool.py
```

### 4. 启动应用

```bash
# 使用 uvicorn 启动
uvicorn app.main:app --host 0.0.0.0 --port 8000 --workers 3

# 或使用 gunicorn
gunicorn app.main:app -w 3 -k uvicorn.workers.UvicornWorker
```

## 🔧 故障排查

### 连接池问题

```bash
# 检查连接池状态
python scripts/monitor_db_pool.py

# 检查 MySQL 连接数
mysql -u root -p -e "SHOW STATUS LIKE 'Threads_connected';"
```

### 慢查询问题

```bash
# 查看慢查询日志
tail -f /var/log/mysql/slow.log

# 分析慢查询
mysqldumpslow -s t /var/log/mysql/slow.log
```

### 缓存问题

```bash
# 检查 Redis 连接
redis-cli ping

# 查看缓存统计
redis-cli INFO stats
```
