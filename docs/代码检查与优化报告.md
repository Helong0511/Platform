### 2. 数据库查询优化 ⚠️

#### 2.1 N+1查询问题 ⚠️

**发现的问题**:
```python
# 可能的N+1问题
# 在循环中查询数据库
for item in items:
    user = await db.get(User, item.user_id)  # N+1问题
```

**建议**:
```python
# 使用join或eager loading
from sqlalchemy.orm import selectinload

result = await db.execute(
    select(Item)
    .options(selectinload(Item.user))
    .where(Item.id.in_(item_ids))
)
items = result.scalars().all()
# 现在items[0].user已经加载，不会触发额外查询
```
