# Telegram 自动通知客户测试用例

## 一、测试概述

本文档提供 Telegram 自动通知客户功能的完整测试用例，用于验证系统功能是否正常工作。

## 二、测试环境准备

### 2.1 前置条件

1. ✅ 数据库迁移已执行
2. ✅ 后端服务已启动
3. ✅ 前端服务已启动
4. ✅ Redis 服务已启动（可选，但推荐）
5. ✅ Telegram Bot 已配置并启动
6. ✅ 测试客户已创建
7. ✅ 测试产品已创建

### 2.2 测试数据准备

1. **测试客户**
   - 客户ID：1
   - 客户名称：测试客户A
   - Telegram Chat ID：测试用的 Chat ID

2. **测试产品**
   - 产品ID：1
   - 产品名称：测试产品A
   - 关联客户：测试客户A

## 三、功能测试用例

### 3.1 实时通知测试

#### 测试用例 TC-001：实时通知发送

**测试步骤**：
1. 配置客户通知：
   - 启用通知：✅
   - 通知转化事件：✅
   - 通知渠道：Telegram ✅
   - Telegram Chat ID：填写测试 Chat ID
   - 通知频率：实时通知

2. 触发转化（通过 Postback API）

3. 验证结果：
   - [ ] 客户收到 Telegram 通知
   - [ ] 通知消息格式正确
   - [ ] 通知记录保存到数据库（`conversion_id` 不为 NULL）
   - [ ] 通知状态为 `sent`

**预期结果**：
- 转化发生后立即收到通知
- 通知消息包含：产品名称、平台、转化ID、金额、时间等
- 通知记录正确保存

### 3.2 每小时汇总通知测试

#### 测试用例 TC-004：每小时汇总通知发送

- 每小时只收到 1 条汇总通知
- 汇总消息包含所有转化的统计信息
- 通知记录正确保存
