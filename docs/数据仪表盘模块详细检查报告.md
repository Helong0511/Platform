### 🔴 严重问题

#### 1. **后端查询结果空值处理不一致**
**位置：** `app/api/api_v1/endpoints/dashboard.py:242-258`

**问题：**
```python
trend_requests = calculate_trend(result.total_requests, result_prev.total_requests if result_prev else 0)
```
当 `result` 为 `None` 时，访问 `result.total_requests` 会抛出 `AttributeError`。

**当前代码：**
```python
# 第145行：处理了 result 为 None 的情况
if result is None:
    total_revenue = 0.0
    total_impressions = 0.0
# 但第242行：直接访问 result.total_requests，没有检查 result 是否为 None
trend_requests = calculate_trend(result.total_requests, ...)
```

**修复建议：**
```python
# 在计算趋势前，确保 result 不为 None
if result is None:
    # 返回空数据
    response_data = DashboardStatsResponse(
        stats=[],
        metrics={"total_revenue": 0.0, "roi": 0.0}
    )
    await set_cached(cache_key, response_data.model_dump(), ttl=60)
    return ResponseBaseSchema.success(data=response_data)

# 或者在使用前添加安全检查
trend_requests = calculate_trend(
    result.total_requests if result else 0, 
    result_prev.total_requests if result_prev else 0
)
```

#### 2. **趋势数据转换可能的数据不一致**
**位置：** `frontend/src/views/Dashboard.vue:200-211`

**问题：**
如果 `seriesItem.data` 的长度与 `dates` 长度不一致，会导致数据错位。

**当前代码：**
```javascript
dates.forEach((date, dateIndex) => {
  series.forEach((seriesItem) => {
    if (seriesItem && seriesItem.name && Array.isArray(seriesItem.data)) {
      const value = seriesItem.data[dateIndex] || 0;  // 如果 data 长度不足，会取 undefined
      transformedData.push({
        date: date,
        type: seriesItem.name,
        value: value
      });
    }
  });
});
```

**修复建议：**
```javascript
dates.forEach((date, dateIndex) => {
  series.forEach((seriesItem) => {
    if (seriesItem && seriesItem.name && Array.isArray(seriesItem.data)) {
      // 确保索引有效
      const value = (dateIndex < seriesItem.data.length) 
        ? (seriesItem.data[dateIndex] || 0) 
        : 0;
      transformedData.push({
        date: date,
        type: seriesItem.name,
        value: value
      });
    }
  });
});
```
