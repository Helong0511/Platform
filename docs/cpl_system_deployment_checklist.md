## 🔍 问题排查

### 问题1：数据库迁移失败
**症状**：执行SQL脚本时出错

**排查步骤**：
1. 检查数据库连接
2. 检查数据库权限
3. 检查SQL脚本语法
4. 查看详细错误信息

**解决方案**：
- 确认数据库用户有足够权限
- 检查SQL脚本是否有语法错误
- 查看MySQL错误日志

### 问题2：前端页面无法访问
**症状**：访问CPL系统页面时404或空白

**排查步骤**：
1. 检查路由配置
2. 检查菜单配置
3. 查看浏览器控制台
4. 查看后端日志

**解决方案**：
- 确认路由已注册（`frontend/src/router/index.js`）
- 确认菜单已配置（`frontend/src/components/Layout/Sidebar.vue`）
- 清除浏览器缓存
- 重启前端服务

### 问题3：API返回404
**症状**：前端调用API时返回404

**排查步骤**：
1. 检查API路由注册
2. 检查后端服务状态
3. 查看后端日志

**解决方案**：
- 确认API路由已注册（`app/api/api_v1/api.py`）
- 确认后端服务正常运行
- 检查API路径是否正确

### 问题4：Cap检查不生效
**症状**：达到Cap后仍然允许转化

**排查步骤**：
1. 检查Cap配置是否正确
2. 检查Cap检查逻辑是否被调用
3. 查看日志中的Cap相关信息

**解决方案**：
- 确认Cap配置已创建且激活
- 检查Postback处理逻辑
- 查看日志中的Cap检查结果
