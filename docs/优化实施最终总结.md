## 📋 配置建议

### 数据库连接池

**当前配置：**
- `DB_POOL_SIZE=15`（每个 worker）
- `DB_MAX_OVERFLOW=10`（每个 worker）
- `DB_POOL_RECYCLE=3600`（1 小时）

**优化建议：**
- 高负载环境：`DB_POOL_SIZE=20`, `DB_MAX_OVERFLOW=15`
- 低负载环境：`DB_POOL_SIZE=10`, `DB_MAX_OVERFLOW=5`

### MySQL 配置

```ini
[mysqld]
max_connections = 200
innodb_buffer_pool_size = 2G
innodb_log_file_size = 256M
slow_query_log = 1
long_query_time = 1
```

### Redis 配置（可选）

- 启用 Redis 缓存可进一步提升性能
- 预期缓存命中率：60%+
- 缓存命中时响应时间：<0.1s
