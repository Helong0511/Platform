# 短链接渠道参数处理逻辑说明

## 一、业务场景

### 1.1 渠道原始短链接点击URL示例

```
https://client.btfrx.online/s/WRhR?offer_id=11&channel_id=4&click_id=wnDYcdbppM3dBkeNAtf4ncebHzEhz8TM&sub_channel_id=1000
```

### 1.2 参数分类

#### 系统必须参数（System Required Parameters）
- `offer_id=11` - Offer ID（必须）
- `channel_id=4` - 渠道ID（必须）

**处理逻辑：**
- 如果URL参数中没有，则从短链接记录中查找
- 如果查找不到，**不跳转，不保存访问记录，只打印日志，返回400错误**

#### 渠道参数（Channel Parameters）
- `click_id=wnDYcdbppM3dBkeNAtf4ncebHzEhz8TM` - 渠道提供的原始click_id
- `sub_channel_id=1000` - 子渠道ID
- 其他渠道自定义参数...

**处理逻辑：**
- 保存到 `clicks.url_params` 字段（JSON格式）
- 用于转化时转发给渠道
- **如果参数值包含占位符（如 `{click_id}`），则抛弃该参数**

## 二、处理流程

### 2.1 短链接重定向流程

```
1. 接收渠道请求
   ↓
2. 提取参数
   - offer_id, channel_id (系统参数)
   - click_id, sub_channel_id, ... (渠道参数)
   ↓
3. 验证必须参数
   - 如果缺少 offer_id 或 channel_id，返回400错误，不保存记录
   ↓
4. 生成系统 click_id
   - 例如：0123456789AbCdEf
   ↓
5. 提取并过滤渠道参数
   - 排除 offer_id, channel_id
   - 过滤掉包含占位符的参数
   - 保存到 url_params
   ↓
6. 替换占位符
   - 原始URL: http://keplerads.fuse-ad.com/tl?a=3058&o=7361&aff_click_id={click_id}&sub_affid={channel_id}
   - 替换后: http://keplerads.fuse-ad.com/tl?a=3058&o=7361&aff_click_id=0123456789AbCdEf&sub_affid=4
   ↓
7. 构建最终URL
   - 如果原始URL没有 click_id 占位符，添加系统生成的 click_id
   - 例如: http://keplerads.fuse-ad.com/tl?a=3058&o=7361&click_id=0123456789AbCdEf&sub_affid=4
   ↓
8. 创建Click记录
   - click_id: 0123456789AbCdEf (系统生成)
   - offer_id: 11
   - publisher_id: 4
   - url_params: {"click_id": "wnDYcdbppM3dBkeNAtf4ncebHzEhz8TM", "sub_channel_id": "1000"}
   ↓
9. 302重定向到最终URL
```

### 2.2 转化转发流程

```
1. 接收转化回调
   - click_id: 0123456789AbCdEf (系统生成的)
   - payout: 2.80 (原始金额)
   ↓
2. 查找Click记录
   - 通过系统生成的 click_id 查找
   - 获取 url_params 字段
   ↓
3. 应用扣量逻辑
   - 原始金额: 2.80
   - 扣减后金额: 2.24 (假设扣减20%)
   ↓
4. 构建转发数据
   - click_id: wnDYcdbppM3dBkeNAtf4ncebHzEhz8TM (渠道原始click_id)
   - sub_channel_id: 1000
   - payout: 2.24 (扣减后的金额)
   ↓
5. 转发给渠道
```

## 三、关键代码位置

### 3.1 渠道参数提取

**文件：** `app/routes/short_link_redirect.py`

**函数：** `_extract_and_filter_channel_params()`

```python
def _extract_and_filter_channel_params(request_params: dict) -> dict:
    """
    提取并过滤渠道参数
    
    从请求参数中提取除 offer_id 和 channel_id 之外的所有参数，
    并过滤掉包含占位符的参数。
    
    这些参数将保存到 clicks 表的 url_params 字段，用于转化时转发给渠道。
    """
    # 占位符正则表达式：匹配 {变量名} 格式
    placeholder_pattern = re.compile(r'\{[a-zA-Z_][a-zA-Z0-9_]*\}')
    
    # 需要排除的参数（系统参数，不需要保存到 url_params）
    excluded_params = {'offer_id', 'channel_id', 'publisher_id'}
    
    channel_params = {}
    
    # 遍历所有请求参数，排除系统参数，并过滤掉包含占位符的参数
    for key, value in request_params.items():
        key_lower = key.lower()
        
        # 跳过系统参数（offer_id 和 channel_id）
        if key_lower in excluded_params:
            continue
        
        # 处理列表值
        if isinstance(value, list):
            value = value[0] if value else ''
        
        # 将值转为字符串进行检查
        value_str = str(value) if value else ''
        
        # 如果值不包含占位符，则保存
        if value_str and not placeholder_pattern.search(value_str):
            channel_params[key] = value
    
    return channel_params
```

### 3.2 占位符替换

**文件：** `app/routes/short_link_redirect.py`

**函数：** `_replace_short_link_placeholders()`

**关键点：**
- 使用**系统生成的 click_id** 替换占位符
- 支持多种占位符格式：`{click_id}`, `{clickId}`, `{aff_click_id}` 等
- 支持 `{channel_id}`, `{sub_affid}` 等渠道ID占位符

### 3.3 最终URL构建

**文件：** `app/routes/short_link_redirect.py`

**函数：** `_build_final_url()`

**关键点：**
- **最终URL只包含必须参数（click_id 和 channel_id），不包含其他参数**
- 检查替换后的URL是否包含 `click_id`（支持多种参数名：`click_id`, `aff_click_id`, `clickId` 等）
- 检查替换后的URL是否包含 `channel_id`（支持多种参数名：`channel_id`, `sub_affid`, `channelId` 等）
- 提取必须参数的值（如果已存在）
- 如果缺少 `click_id`，使用系统生成的 `click_id`
- 如果缺少 `channel_id`，使用 `channel_id`
- **移除原始URL中的所有其他参数**（如 `a=3058`, `o=7361` 等）
- **使用标准参数名**（`click_id` 和 `channel_id`）

### 3.4 转化转发

**文件：** `app/core/postback/forwarder.py`

**函数：** `_build_forward_data()`

**关键点：**
- 从 `clicks.url_params` 中提取渠道参数
- 使用**扣减后的 payout**（`conversion.payout`）
- 特别处理 `click_id` 和 `sub_channel_id`

```python
@staticmethod
def _build_forward_data(
    conversion: PostbackConversion,
    click_params: Optional[Dict[str, Any]] = None
) -> Dict[str, Any]:
    """
    构建转发给下游的数据
    
    将转化记录转换为字典格式，用于转发给下游系统
    注意：payout 字段使用扣后的 payout（PO(扣)），这是给下游的实际金额
    """
    data = {
        "conversion_id": conversion.conversion_id,
        "platform": conversion.platform,
        "event_name": conversion.event_name,
    }
    
    # payout 字段使用扣后的 payout（给下游的实际金额）
    if conversion.payout is not None:
        data["payout"] = conversion.payout
    elif conversion.original_payout is not None:
        # 如果没有扣后的 payout，使用原始的 payout
        data["payout"] = conversion.original_payout
    
    # 合并原始点击参数（如果有）
    if click_params:
        for key, value in click_params.items():
            # 只添加转化数据中不存在的字段，避免覆盖转化数据
            if key not in data and value is not None:
                # 处理列表值
                if isinstance(value, list):
                    data[key] = value[0] if len(value) == 1 else value
                else:
                    data[key] = value
    
    # 特别处理：如果click_params中有click_id（渠道提供的），确保添加到转发数据中
    if click_params and 'click_id' in click_params:
        click_id_value = click_params['click_id']
        if isinstance(click_id_value, list):
            click_id_value = click_id_value[0] if click_id_value else None
        if click_id_value:
            # 使用渠道提供的click_id，而不是系统生成的click_id
            if 'click_id' not in data or data.get('click_id') == conversion.click_id:
                data['click_id'] = click_id_value
    
    # 特别处理：如果click_params中有sub_channel_id，确保添加到转发数据中
    if click_params and 'sub_channel_id' in click_params:
        sub_channel_id_value = click_params['sub_channel_id']
        if isinstance(sub_channel_id_value, list):
            sub_channel_id_value = sub_channel_id_value[0] if sub_channel_id_value else None
        if sub_channel_id_value:
            data['sub_channel_id'] = sub_channel_id_value
    
    return data
```

## 五、注意事项

### 5.1 占位符处理

- **渠道参数中的占位符会被过滤掉**
  - 例如：如果渠道传入 `test={click_id}`，该参数会被抛弃
  - 原因：占位符无法在转化时替换，会导致转发数据不完整

### 5.2 click_id 的双重含义

- **系统生成的 click_id**：
  - 用于替换原始URL中的占位符
  - 用于关联Click记录和转化记录
  - 存储在 `clicks.click_id` 字段

- **渠道提供的 click_id**：
  - 保存在 `clicks.url_params` 字段
  - 用于转化时转发给渠道
  - 不会用于替换占位符

### 5.3 必须参数验证

- 如果缺少 `offer_id` 或 `channel_id`：
  - 不跳转
  - 不保存访问记录
  - 不创建Click记录
  - 只打印日志
  - 返回400错误

### 5.4 扣量后的 payout

- 转发给渠道的 `payout` 是**扣减后的金额**
- 原始金额保存在 `conversion.original_payout` 字段
- 扣减后的金额保存在 `conversion.payout` 字段

### 5.5 最终URL构建规则

- **只包含必须参数**：最终URL只包含 `click_id` 和 `channel_id`，移除所有其他参数
- **使用标准参数名**：统一使用 `click_id` 和 `channel_id` 作为参数名
- **支持多种参数名识别**：能够识别替换后URL中的多种参数名形式：
  - `click_id`: `click_id`, `aff_click_id`, `clickId`, `clickid`, `CLICK_ID`, `AFF_CLICK_ID` 等
  - `channel_id`: `channel_id`, `sub_affid`, `channelId`, `channelid`, `CHANNEL_ID`, `SUB_AFFID` 等
- **参数值提取**：如果替换后的URL已包含必须参数，提取其值；如果缺少，使用系统生成的值
- **示例**：
  - 输入：`http://example.com?a=3058&o=7361&aff_click_id=0123456789AbCdEf&sub_affid=4`
  - 输出：`http://example.com?click_id=0123456789AbCdEf&channel_id=4`
  - 说明：提取了 `aff_click_id` 和 `sub_affid` 的值，移除了 `a=3058` 和 `o=7361`，使用标准参数名
