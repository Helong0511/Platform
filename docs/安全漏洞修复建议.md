## 🔴 严重安全问题：硬编码的API密钥和密码

### 问题描述

在以下文件中发现了硬编码的API密钥和密码：

1. **`app/scheduler_module/tasks/tqt_task.py`**
   ```python
   tqt_api_secret = 'cglnhl8pbg8zl4b9a44c4qofdrb6rwn4'
   ```

2. **`app/scheduler_module/tasks/skymobi_task.py`**
   ```python
   api_key = '67b7c7fac2154bb8f59546d9b23058c9'
   ```

3. **`app/scheduler_module/tasks/tbsj_task.py`**
   ```python
   password = '5e2296fa9fd1434bf8a60c03cf745ce9'
   ```

4. **`app/scheduler_module/tasks/addermobi_task.py`**
   ```python
   password = 'lw145667'
   ```

### 安全风险

- **代码仓库泄露风险**: 如果代码仓库被公开或泄露，这些密钥会立即暴露
- **版本控制历史**: 即使后续删除，密钥仍会保留在Git历史中
- **密钥泄露影响**: 攻击者可以使用这些密钥访问第三方API服务

### 修复步骤

#### 步骤1: 立即更换已泄露的密钥

如果代码仓库是公开的或可能已泄露，**立即联系相关服务提供商更换所有密钥**。

#### 步骤2: 迁移到环境变量

1. **更新 `.env.example` 文件**:
   ```bash
   # TQT API配置
   TQT_API_SECRET=your_tqt_api_secret_here
   
   # Skymobi API配置
   SKYMOBI_API_KEY=your_skymobi_api_key_here
   SKYMOBI_API_ID=your_skymobi_api_id_here
   
   # TBSJ API配置
   TBSJ_PASSWORD=your_tbsj_password_here
   
   # Addermobi API配置
   ADDERMOBI_PASSWORD=your_addermobi_password_here
   ```

2. **更新配置文件** (`app/core/config.py`):
   ```python
   # ====== 第三方API配置 ======
   TQT_API_SECRET: str = os.getenv("TQT_API_SECRET", "")
   SKYMOBI_API_KEY: str = os.getenv("SKYMOBI_API_KEY", "")
   SKYMOBI_API_ID: str = os.getenv("SKYMOBI_API_ID", "")
   TBSJ_PASSWORD: str = os.getenv("TBSJ_PASSWORD", "")
   ADDERMOBI_PASSWORD: str = os.getenv("ADDERMOBI_PASSWORD", "")
   ```

3. **更新任务文件** (`app/scheduler_module/tasks/tqt_task.py`):
   ```python
   from app.core.config import settings
   
   # TQT API配置
   tqt_url = 'https://union.e-kivi.com/open/api/report/data'
   tqt_app_key = '07ycrvnf'
   tqt_api_secret = settings.TQT_API_SECRET
   
   if not tqt_api_secret:
       logger.error("TQT_API_SECRET 未配置，TQT任务将无法执行")
   ```

4. **更新其他任务文件**（类似方式）

#### 步骤3: 清理Git历史（可选但推荐）

如果代码仓库是私有的且密钥可能已泄露，考虑清理Git历史：

```bash
# 使用 git-filter-repo 工具清理历史
git filter-repo --path app/scheduler_module/tasks/tqt_task.py \
                --path app/scheduler_module/tasks/skymobi_task.py \
                --path app/scheduler_module/tasks/tbsj_task.py \
                --path app/scheduler_module/tasks/addermobi_task.py \
                --invert-paths \
                --force
```

**注意**: 这会重写Git历史，需要所有团队成员重新克隆仓库。

#### 步骤4: 添加密钥验证

在应用启动时验证必需的密钥：

```python
# app/main.py 的 lifespan 函数中
if settings.is_production:
    required_keys = [
        ("TQT_API_SECRET", settings.TQT_API_SECRET),
        ("SKYMOBI_API_KEY", settings.SKYMOBI_API_KEY),
        # ... 其他密钥
    ]
    
    missing_keys = [name for name, value in required_keys if not value]
    if missing_keys:
        logger.error(f"生产环境缺少必需的API密钥: {', '.join(missing_keys)}")
        raise ValueError(f"生产环境必须配置以下环境变量: {', '.join(missing_keys)}")
```

#### 步骤5: 使用密钥管理服务（推荐）

对于生产环境，建议使用专业的密钥管理服务：

- **AWS Secrets Manager**
- **HashiCorp Vault**
- **Azure Key Vault**
- **Google Cloud Secret Manager**

### 预防措施

1. **添加 pre-commit 钩子**:
   ```bash
   # .git/hooks/pre-commit
   #!/bin/bash
   # 检查是否包含硬编码的密钥模式
   if git diff --cached | grep -E "(api_key|api_secret|password|secret_key)\s*=\s*['\"][^'\"]+['\"]"; then
       echo "错误: 检测到可能的硬编码密钥，请使用环境变量"
       exit 1
   fi
   ```

2. **使用 Git Secrets**:
   ```bash
   git secrets --install
   git secrets --register-aws
   ```

3. **代码审查**: 在代码审查时特别注意硬编码的密钥

4. **定期审计**: 定期扫描代码库查找硬编码密钥

## 其他安全建议

### 动态导入安全性

**文件**: `app/scheduler_module/task_registry.py`

**当前实现**:
```python
module = __import__(module_path, fromlist=[function_name])
```

**建议增强**:
```python
# 白名单验证
ALLOWED_MODULE_PREFIXES = ['app.scheduler_module.tasks']

def validate_module_path(module_path: str) -> bool:
    """验证模块路径是否安全"""
    # 检查是否在白名单中
    if not any(module_path.startswith(prefix) for prefix in ALLOWED_MODULE_PREFIXES):
        return False
    
    # 防止路径遍历攻击
    if '..' in module_path or '/' in module_path or '\\' in module_path:
        return False
    
    return True

# 在使用前验证
if not validate_module_path(module_path):
    raise ValueError(f"不允许的模块路径: {module_path}")
```
